# Dark Harmony - btop theme

A simple **black and red** theme for [btop](https://www.github.com/aristocratos/btop).

## Installation

Copy `dark_harmony.theme` to your btop themes directory:

```bash
> copy dark_harmony.theme $HOME/.config/btop/themes/
```

Then select **dark_harmony** from the btop options menu.

## Preview

The theme uses:

* Black background
* White primary text
* Bright red highlights and graphs
* Dark red selection background
* Grey inactive text
